# Đồ Án Khai Phá Dữ Liệu: Dự Đoán Nhân Viên Nghỉ Việc

Dự án nghiên cứu và ứng dụng các kỹ thuật Khai phá dữ liệu (Data Mining) & Học máy (Machine Learning) để phân tích các yếu tố ảnh hưởng và dự đoán nguy cơ nghỉ việc của nhân viên trong doanh nghiệp.

## Thành viên thực hiện
- **Lê Nhật Trường**
- **Nguyễn Minh Thiện**

---

## Cấu trúc thư mục

| Tên tệp / Thư mục | Mô tả |
| :--- | :--- |
| `LeNhatTruong_NguyenMinhThien_dudoanNVnghi.ipynb` | Notebook chứa toàn bộ quy trình: Khám phá dữ liệu (EDA), Tiền xử lý, Xây dựng mô hình, Đánh giá và So sánh các thuật toán |
| `LNT_NMT.csv` | Tập dữ liệu dùng cho huấn luyện và kiểm thử mô hình |
| `BaoCao_DoAn_DuDoanNghiViec.docx` | Báo cáo chi tiết đồ án môn học |
| `ThuyetTrinh_DuDoanNghiViec.pptx` | Slide thuyết trình đồ án |

---

## Công nghệ & Thư viện sử dụng
- **Ngôn ngữ**: Python
- **Môi trường**: Jupyter Notebook
- **Thư viện chính**:
  - Phân tích & Xử lý dữ liệu: `pandas`, `numpy`
  - Trực quan hóa dữ liệu: `matplotlib`, `seaborn`
  - Học máy & Khai phá dữ liệu: `scikit-learn` (và các thư viện liên quan)

---

## Hướng dẫn chạy Notebook
1. Cài đặt các thư viện cần thiết:
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter
   ```
2. Mở Jupyter Notebook:
   ```bash
   jupyter notebook LeNhatTruong_NguyenMinhThien_dudoanNVnghi.ipynb
   ```
3. Chạy từng ô lệnh theo thứ tự để xem kết quả tiền xử lý và huấn luyện mô hình.
